# 🛡️ TeleShield

TeleShield 是一個給 macOS 使用的 Telegram 私訊防護工具。

它會在你的電腦上檢查陌生人的私訊，遇到高信心的廣告、詐騙或導流訊息時，可以在你看見內容前直接封鎖對方。

## 為什麼需要它？

Telegram 有以「付費訊息」限制陌生人傳訊息的防垃圾訊息方式，但對沒有 Telegram 付費方案、或目前無法使用這項功能的帳號來說，便不能靠這個設定限制非聯絡人私訊。結果是，廣告、投資推銷、賭博、色情、假冒客服或其他可疑內容，仍可能直接出現在你的訊息列表中。

TeleShield 的目的，就是在這個情境下提供一個本機可控的替代方案：

- 不需要改用另一個 Telegram 帳號。
- 不需要把訊息交給額外的雲端分析服務。
- 可以先預覽判斷結果，再決定是否封鎖。
- 可以用白名單、黑名單與自己的規則調整行為。

它不會改變 Telegram 的付費設定，也不保證所有垃圾訊息都能被辨識；它提供的是一層可以自行管理、逐步調整的個人防護。

> ## 重要：TeleShield 主要是保護「非聯絡人」
>
> 一般模式的垃圾訊息辨識，主要只會檢查非聯絡人的一對一私訊。已經在 Telegram 聯絡人中的人，以及白名單對象，會跳過這套一般垃圾訊息規則，不會因為訊息中出現「投資」或「優惠」等字眼就被自動封鎖。
>
> 這不是用來監看或封鎖所有聊天的 App，而是用來擋住陌生人第一次傳來的廣告、詐騙和導流訊息。

## 它可以做什麼？

- **主要防護對象：非聯絡人的一對一私訊。**
- 第一則訊息就開始判斷，不需要等對方傳網址。
- 辨識投資、賭博、色情、詐騙、兼職、促銷與加好友導流等內容。
- 讀取圖片中的文字，再用同一套規則判斷。
- 使用白名單、黑名單與自己的學習規則。
- 把封鎖結果保存在本機，方便日後查看。

TeleShield 不是 Telegram 官方 App，也不是群組管理機器人；它是你自己帳號的額外防護層。

## 帳號盜用型釣魚訊息

TeleShield 也會特別檢查常見的 Telegram 假通知。這類訊息不一定有網址，可能先說帳號異常、功能受限或偵測到可疑活動，再要求恢復帳號、解除限制、輸入驗證碼、登入網站或掃描 QR Code。

判斷時會一起看多組訊號，例如：

- 帳號異常、限制、凍結或停用。
- 恢復帳號、申訴或解除限制。
- 輸入登入碼、驗證碼、手機號碼或掃描 QR Code。
- 冒充 Telegram 官方、客服、安全中心或系統通知。
- 「立即處理」「24 小時內」等催促語氣。

繁體中文、簡體中文和英文都會辨識，也會處理空格、符號、英文數字插入與 OCR 讀出的文字。只有單獨出現「客服」「投票」或「驗證帳號」等一般詞語時，會先保留；完整的恢復帳號、交出登入碼、掃描 QR Code 等高風險要求，或多組可疑訊號一起出現時，會提高為高信心釣魚訊息並封鎖非聯絡人。

## 兩種防護模式

在「帳號詳細設定 → 防護政策」可以選擇模式。兩種模式都會先保留聯絡人與白名單，差別只在其他非聯絡人：

- **一般模式：**檢查非聯絡人的訊息，只有高信心的垃圾訊息會被封鎖，正常訊息會保留。
- **嚴格模式：**聯絡人與白名單仍然保留，其他非聯絡人直接封鎖，不再等待內容判斷。

第一次使用建議先整理白名單。封鎖或刪除對話可能無法復原。

## 變形字也能辨識

廣告常會在中文字中間插入空格、符號、英文、數字或 emoji 來躲避關鍵字。TeleShield 會另外抽出中文字，再檢查拼音與注音。

例如下面這些文字可以辨識：

```text
偷price姿321       → 投資
偷12g姿pri22       → 投資
詐asg片333         → 詐騙
堵888伯ccc         → 賭博
頭🤑3茲price       → 投資
```

也會處理常見的全形符號、空格、零寬字元、簡繁字、同音字、拼音與注音。

英文規則仍然照原本方式判斷，不會因為中文骨架功能而把英文、網址或數字刪掉。

英文的 Telegram、LINE 和使用者名稱格式會保留單字邊界，不會把一般句子中的字母跨單字拼成假的 `tg` 帳號。例如 `just got more` 不會因為去除空格後出現 `tg` 就被封鎖；但 `tg @username`、`telegram: username` 和 `t.me` 連結仍會照規則判斷。

### 拼音和注音

系統會同時看：

- 有聲調的拼音與注音。
- 沒有聲調的拼音與注音。
- 中文原文與變形後的中文字。

有聲調可以提高準確度；沒有聲調可以抓到廣告故意改聲調的寫法。

### 自己學習規則

你可以把看到的廣告加入學習規則。學習後，中文關鍵字會自動支援：

- 空格、符號、英文、數字與 emoji 插入。
- 拼音與注音。
- 同音字與簡繁字。

例如你學習「投資」，之後收到「偷price姿321」，仍然會命中這條規則並封鎖。

英文學習規則則維持英文比對方式，不會被中文規則改變。

## 圖片文字辨識

非聯絡人傳送圖片時，TeleShield 可以先用 macOS 內建的 Vision OCR 讀取圖片文字，再交給文字防護規則判斷。

例如圖片中的：

```text
頭姿
頭茲
頭資
```

會被當成「投資」的變形處理。

圖片本身不會直接造成封鎖，必須先讀到可疑文字並命中規則。圖片清晰度、字體和背景都可能影響辨識結果。

OCR 讀到的文字也會經過同樣的繁簡、拼音、注音、骨架和導流／釣魚規則。OCR 中不同區域的換行或介面文字，不會單獨被當成變形字加分；只有命中詞附近的插字、符號或數字才會提高變形判斷。

## 封鎖記錄與通知

封鎖記錄不只保存訊息摘要，也會保存容易理解的分析結果：

- 封鎖原因，例如高信心垃圾訊息、疑似帳號釣魚、黑名單或嚴格模式。
- 分類、導流意圖、命中規則、分數與分析來源（文字或 OCR）。釣魚訊息會顯示釣魚風險分數，不會誤用一般垃圾訊息分數。
- 內容摘要只顯示前 30 個字元，避免在通知中傳送整段訊息。

如果開啟 Telegram Bot 通知，通知中的「帳號」會是目前登入的帳號；「封鎖名稱」會是實際被封鎖的對象。這些資料會依每次事件動態產生，不會固定使用某個帳號。Telegram 原生系統通知則無法由 TeleShield 修改。

## 白名單、黑名單與歷史掃描

- **聯絡人與白名單：**信任的人不會被一般垃圾訊息規則處理。
- **黑名單：**已知的騷擾帳號直接封鎖。
- **歷史掃描：**檢查已經收到的非聯絡人私訊。預覽模式只顯示結果，不會封鎖；確認後才會執行。

## 封鎖後的選項

以下功能可以自行開關，預設關閉：

- 封鎖後刪除一對一聊天室。
- 封鎖後用 Telegram Bot 發送通知。

這些功能失敗時，不會影響原本的封鎖結果。

## 開始使用

### 需要什麼？

- macOS 13 或更新版本。
- 你自己控制的 Telegram 個人帳號。
- Telegram API ID 和 API Hash，可從 [Telegram API tools](https://my.telegram.org/auth?to=apps) 申請。

### 第一次設定

1. 將 `TeleShield.app` 拖到「應用程式」資料夾。
2. 開啟 App，新增 Telegram 帳號。
3. 輸入 API ID、API Hash、手機號碼與 Telegram 驗證碼。
4. 如果有開啟兩步驟驗證，再輸入 2FA 密碼。
5. 先加入白名單，再啟動防護。

API 憑證、驗證碼、2FA 密碼和 Session 都是敏感資料，不要分享或上傳。

### macOS 阻擋 App 開啟時

目前 DMG 是未簽署的測試版。如果 macOS 顯示無法確認開發者，請先把 App 放到 `/Applications`，再在終端機執行：

```bash
xattr -dr com.apple.quarantine "/Applications/TeleShield.app"
open "/Applications/TeleShield.app"
```

只對你信任的 App 使用這個指令。如果 App 已經可以開啟，就不需要執行。

## 安全提醒

- 只用在你自己控制的 Telegram 帳號。
- Session 等同登入憑證，請勿分享。
- TeleShield 不保證能抓到所有垃圾訊息。
- 啟用嚴格模式前，請確認聯絡人與白名單已整理好。
- 刪除聊天記錄可能無法復原。
- 目前主要處理非聯絡人的一對一私訊，不管理群組或頻道。
